# Planning documents

`docs/planning/07-wave-3-implementation-tasks.md` is the live wave 3 tracker; `06-wave-3-gap-assessment.md` is its evidence base. When you finish, change, or discover work, tick or edit the matching `W3-xx` task and record any decision in its §1 gate table instead of creating a new document.

Everything else under `docs/planning/` (including `ui-audit/`, `00`–`05`) is historical: do not edit it, except to add a one-line pointer when a decision supersedes it. Never claim a task is done without a passing test or e2e run that proves it.
