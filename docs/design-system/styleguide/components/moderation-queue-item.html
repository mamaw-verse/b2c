Moderation · Phase 4

ModerationQueueItem

Queue row: type icon, title, excerpt, StatusPill, age/SLA, reporter count, priority.

1. Purpose2. Anatomy3. Variants and sizes4. States5. Responsive behaviour6. API / props7. Accessibility8. Tokens used9. Content rules10. Do / Don’t11. HTML usage12. Test notes

1. Purpose

Use when

  • Moderation queue list.

Don’t use when

  • Seller order lists (OrderRow).

2. Anatomy

  1. Bulk checkbox (md+, 44px).
  2. Type tile: Listing, Review, Chat, Seller application, User/Shop report, Dispute.
  3. ID (tabular) + priority badge.
  4. Title link (stretched row) + excerpt.
  5. StatusPill · age + SLA (warn 15 min before, breach = danger) · “N reports”.

7. Accessibility

Role
List item; stretched title link.
Accessible name
Row contents read naturally; priority has sr-only prefix.
Keyboard
Tab to row link; checkbox toggles bulk mode.
Focus management
Follows DOM order; no focus is moved programmatically.
ARIA
aria-current on the open item.
Touch target
44px minimum (min-h-touch); primary actions 48px.
Reduced motion
Transitions use --dur* tokens, which collapse to 1ms under prefers-reduced-motion.
Announcements
Bulk count via aria-live in BulkActionBar.
