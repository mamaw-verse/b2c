Focus

One indicator everywhere: a 2px outline in the brand focus colour, offset 2px, shown on :focus-visible only. Fields hug it, composites lift it to the container, filled buttons invert it. Every demo below forces the state with data-force="focus"; press Tab to try the real thing.

Rules

What the pattern guarantees and what the lint enforces.

  • One indicator per focused element: a 2px outline, never a box-shadow ring, never a second outline.
  • Only :focus-visible shows the ring — mouse clicks never trigger it (text inputs excepted: they match :focus-visible so they still indicate focus).
  • Fields keep a neutral border at rest; on focus the ring hugs the border (outline-offset: 0) and the border joins the ring colour. No white gap.
  • Composite controls take .focus-ring (or .focus-ring-inset when an ancestor clips): the container rings, inner parts never do. Dividers stay 1px neutral.
  • Filled brand buttons draw a white ring inside the fill via --focus-ring-on-brand.
  • Errors recolour ring and border to --focus-ring-error; the error text stays visible.
  • Under forced colours the ring uses Highlight. The ring is a static outline, so reduced motion needs nothing.
  • Components never define their own focus colour or width — the lint scan fails on outline:none without a replacement and on focus*:ring|outline|border|shadow utilities.
