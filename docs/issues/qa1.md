### [x] T13. Fix report CSRF (#6)

- **Files:** `resources/js/components/report-dialog.tsx` (≈L109–119), `resources/views/app.blade.php`
- **Do:**
    - Add `<meta name="csrf-token" content="{{ csrf_token() }}">` in `<head>`.
    - In `report-dialog.tsx`, read the cookie first, with the meta as fallback:
        ```ts
        const raw = document.cookie.split('; ').find((c) => c.startsWith('XSRF-TOKEN='))?.slice('XSRF-TOKEN='.length);
        const meta = document.querySelector('meta[name="csrf-token"]')?.getAttribute('content');
        headers: {
            'X-XSRF-TOKEN': raw ? decodeURIComponent(raw) : '',
            ...(meta ? { 'X-CSRF-TOKEN': meta } : {}),
            Accept: 'application/json',
        },
        ```
    - Reason for the cookie: Inertia navigation doesn't refresh `<head>` meta tags, so a meta-only token can go stale after login or logout.

3. **#1:** "Request changes" on non-shop items (products) now flags and logs instead of hiding. Hide still takes a product down. "Warn" is removed until a real `warned` action exists.
4. **#7:** the shop-page Report button is desktop-only (`hidden md:inline-flex`). Decide whether mobile needs an entry point.
